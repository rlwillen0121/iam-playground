# SCIM-to-login first

**Status:** Accepted as the product plan. Not an implementation record.

Ship the SCIM-to-login slice before every native protocol. That slice is v0.1: SCIM, Keycloak, the demo application, fixtures, the CLI, a minimal workbench, and the verifier. An optional MCP and agent-evaluation pack is v0.2, before REST and HR feeds (v0.3) and before OpenLDAP and native Java JDBC (v0.4).

The full lab still includes those native protocols. This decision does not mean any target is implemented. `./lab` does not start services.
